# Introduction
DataGrip is a powerful, cross-platform IDE developed by JetBrains specifically for database developers. It supports a variety of databases like MySQL, PostgreSQL, SQLite, Oracle, and more.

This documentation provides an overview of DataGrip and its key features and usage for managing databases effectively.

![DataGrip Logo](/img/dg.png)

# Usage of DataGrip
#### Support for Multiple Databases
- Connect to MySQL, PostgreSQL, SQL Server, SQLite, Oracle, and more.

#### Smart Query Console
- Allows running queries in different modes and viewing history.

#### Schema Navigation
- Easily jump between tables, views, procedures, and other elements.

#### Code Completion
- Intelligent SQL code completion and suggestions.

#### Version Control Integration
- Built-in Git, Mercurial, and other version control tools.

#### Data Visualization
- View and edit data in table formats, export data as CSV, JSON, etc.

# Installation and Configuration
1. Apply for the free education plicense pack of jetbrains(if not already done) using your bits
email id.

[Link](https://www.jetbrains.com/lp/leaflets-gdc/students/)

2. Once done, install the jetbrains toolbox app
[Link](https://www.jetbrains.com/toolbox-app/)

3. After installing toolbox, open it and sign it with your email(BITS email id)
![Example of sign in page](\img\one.jpg)

4. Using the toolbox download DataGrip and open it.

5. Skip the below page that might appear
![Skip page](\img\two.jpg)

6. Click on new project

7. Click on the plus icon → data sources → select required database(in this case
MySQL)

![SQL page](\img\three.jpg)

8. Enter the required fields with the private credentials provided to you
Ex. For MySQL

![Credentials page](\img\four.jpg)

9. Incase you get a warning asking you to install required drivers click yes, and then
test the connection

10. Click OK and establish connections with all databases in the same manner using
datagrip and your private credentials provided to you.
